# P0 №33c — реестр кандидатов на библиографию

Команда создаёт **локальный CSV для ручной проверки** по существующим регистрациям Store и исходным PDF. Она **ничего не подтверждает, не обновляет Store, не запускает OCR или GigaChat и не готовит официальный выпуск**.

## Запуск на Windows

Установите пакет SPI в используемое Python-окружение либо задайте PYTHONPATH на папку src проверяемой ветки. Корпус и Store берите из вашей локальной рабочей папки, а не из checkout без закрытых файлов.

Пример для PowerShell из checkout новой ветки:

~~~powershell
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
$env:PYTHONPATH = (Resolve-Path ./src).Path

$corpusRoot = 'C:\путь\к\папке\с\данными'
$state = Join-Path $corpusRoot 'outputs/p0-21-test-local/state'
$review = Join-Path $env:TEMP ("spi-bibliography-" + [guid]::NewGuid().ToString("N") + ".csv")

python -B -X utf8 -m spi.bibliography_review --state $state --output $review
~~~

Допустимы опции --domain solar, --domain rag и --publication-id P001 для ограниченной проверки. По умолчанию выбираются все зарегистрированные PDF обоих треков. Каталог для --output должен существовать, а CSV — отсутствовать: перезапись прежнего листа запрещена.

## Колонки и смысл

Одна строка на зарегистрированную публикацию; document_id, pdf_sha256 и физическое число страниц проверяются по исходному PDF до создания листа. Если PDF отсутствует, SHA-256 не совпадает или число страниц изменилось, отчёт не создаётся. Записи сортируются по треку и ID, поэтому неизменный корпус даёт побайтово одинаковый результат.

- Поля *_in_store — уже записанные значения **без вывода об их подтверждении**.
- Поля *_candidate — только подсказки из встроенного словаря PDF, где они доступны.
- Поля *_candidate_source — происхождение подсказки (embedded_pdf_metadata), а не доказательство достоверности.
- review_status=pending, confirmed_*, reviewer, source_pages, source_reference и review_note — **место для ручной проверки**; команда оставляет поля решения пустыми.

Не выводите год публикации из creationDate PDF. Поле DOI может оставаться пустым и должно быть проверено отдельно. Перед одобрением названия, авторов и года проверьте первую страницу, выходные данные, издательскую карточку и наличие переизданий. В source_pages используются **физические номера страниц с единицы**; если значение подтверждалось по издательскому каталогу, сохраните ссылку в source_reference и пояснение в review_note.

CSV сохраняется в UTF-8 BOM для удобства Excel. Начальные символы формул в кандидатах экранируются апострофом, поэтому не удаляйте его автоматически при импорте таблицы. Файл предназначен для локального просмотра, так как содержит сведения об исследованиях.

## Ограничения

Это **этап инвентаризации**, а не механизм применения решения. В текущей версии отсутствует команда apply: ручное заполнение столбцов confirmed_* не изменит Store и не породит официальный publications.csv. Применение будет отдельным этапом с проверкой document_id, SHA-256, фактического основания, автора согласования и страниц/издательского источника, с защитой утверждения при повторном импорте PDF.

Происхождение научных показателей и подтверждение scope остаются независимыми от библиографии. Даже полное подтверждение метаданных не меняет текущий scientific release: BLOCKED.
