## Threat-model review

| Граница | Угроза | Контроль и проверка |
| --- | --- | --- |
| Клиент → Caddy → API | Подмена Host, Origin, forwarded IP или scheme | Единственный доверенный IP Caddy, сверка Host и Origin в API, проверка на HTTP-прокси |
| Сессия → Store | IDOR, подмена ID, traversal, ссылки | Идентификатор владельца из auth DB, существующие проверки путей и межпользовательские тесты |
| Пользовательский PDF → MuPDF | Выполнение кода, исчерпание CPU/RAM, раскрытие других документов | Отдельный сетевой namespace, один входной документ на запрос, ограниченный ответ и отсутствие mount данных приложения |
| Worker → очередь, Store и модель | Потеря checkpoint, повторное выполнение, раскрытие credentials | SQLite locks, проверка владельца и SHA-256, ограничение времени, выключенный GigaChat в локальном Compose |
| Данные → backup и restore | Несогласованный снимок, подмена архива, возврат отозванной сессии | Остановка писателей, SQLite backup API, инвентаризация, контрольные суммы, проверка владельцев и отзыв сессий |
| Хост и оператор → данные | Переполнение диска, доступ к backup или ключам | Файловые квоты Linux, ограниченные tmpfs и логи, шифрование копий вне сервера, отдельный ключ |

Публичный запуск требует проверки настоящего TLS, дисковых квот хоста и восстановления. Нативный разбор PDF в процессе с доступом к другим tenant Store также блокирует допуск.
